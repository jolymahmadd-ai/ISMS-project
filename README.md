# ISMS-project

مشروع تطبيق نظام إدارة أمن المعلومات (ISMS)
يهدف هذا المشروع 
إلى تطبيق متطلبات المواصفة القياسية ISO/IEC 27001:2022 من خلال دراسة حالة "بنك الآفاق الرقمية"، وتحليل الوضع الحالي لأمن المعلومات وتحديد الفجوات الأمنية واقتراح الضوابط والإجراءات اللازمة لمعالجتها.
أهداف المشروع
تطبيق متطلبات ISO/IEC 27001:2022.
تحليل الفجوات الأمنية (Gap Analysis).
تقييم ضوابط الملحق A.
إعداد السياسات والإجراءات الأمنية.
تحسين إدارة المخاطر الأمنية.
تعزيز سرية وسلامة وتوافر المعلومات.
محتويات المشروع
سياسة الاستخدام المقبول (Acceptable Use Policy).
إجراءات الاستجابة للحوادث الأمنية.
تحليل الفجوات الأمنية.
تقييم المخاطر.
ضوابط الملحق A.
الوثائق الداعمة لنظام إدارة أمن المعلومات.
